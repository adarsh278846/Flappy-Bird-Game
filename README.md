# 🐦 Flappy Bird Game

A fun and upgraded version of the classic Flappy Bird game built using Python and Pygame.

## 🎮 About the Game

Flappy Bird Game is a 2D arcade-style game where the player controls a bird and tries to fly through gaps between pipes without hitting them.

The game includes smooth gameplay, sound effects, background music, scoring, lives, and game-over functionality.

## ✨ Features

- 🐦 Smooth bird movement
- 🏆 Score and high-score system
- ❤️ Multiple lives
- 🚧 Random pipe generation
- 🎵 Background music
- 🔊 Sound effects
- 💥 Collision detection
- 🎮 Keyboard controls
- 🔄 Restart functionality
- 💾 Game data storage
- ⚡ Fast and lightweight gameplay

## 🛠️ Technologies Used

- **Python**
- **Pygame**
- **JSON**
- **Git & GitHub**
